# المصحف الشريف

تطبيق ويب قابل للتثبيت (PWA) لقراءة القرآن الكريم بصفحات مصحف المدينة (604 صفحات) بخطوط مجمع الملك فهد.

- علامات على الصفحة والآية، ومتابعة القراءة
- التفسير الميسّر، السعدي، الجلالين، ابن كثير، وترجمة Sahih International
- مشاركة الآية نصاً أو صورة
- الاستماع بأصوات العفاسي والحصري وعبد الباسط والمنشاوي والبنا، مع التكرار للحفظ والتحكم بالسرعة والتنزيل دون إنترنت

افتح الرابط على الجوال ثم «إضافة إلى الشاشة الرئيسية».
